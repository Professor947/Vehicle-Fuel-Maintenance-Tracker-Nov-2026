# M2 manual test checklist (Android device, dev build)

Setup
- [ ] Google Cloud: enable "Places API (New)", create an API key (restrict to Places API).
- [ ] `supabase secrets set GOOGLE_PLACES_API_KEY=...` and `supabase functions deploy places-nearby`.
- [ ] Rebuild the dev client (new native modules: expo-location, react-native-svg).

Refuel flow ("Refueling now?")
- [ ] At a fuel station: tap "Refueling now?" → location permission prompt (while using the app only).
- [ ] Chip shows "Getting location…" then "Location captured"; date/time is pre-filled with now.
- [ ] Station field fills with the nearest station + "Suggested from map"; typing replaces it, and a late
      suggestion never overwrites what you typed.
- [ ] Deny location → "Location unavailable"; the form still saves normally.
- [ ] Airplane mode at a station you used before → station suggested "from your past refuels".
- [ ] Odometer field is focused with the "What does the odometer read now?" hint.

Mileage (use one vehicle; litres = what the pump showed)
- [ ] 1st refuel → Fuel economy shows "Mileage pending" card and "Log two refuels…"; Home says "Mileage pending".
- [ ] 2nd refuel (e.g. +400 km after 10 L) → first interval 40 km/l; cost/km = 10 × rate ÷ 400;
      a new pending card for the 2nd refuel's litres.
- [ ] Add 3 more normal refuels → "Your normal (median)" appears once 3 intervals exist.
- [ ] Next refuel with ~25% less distance → after save, "Unusual drop" dialog opens; choose "Suspected fuel
      theft" + note → interval shows red chip and the cause. Home card shows the drop in red.
- [ ] A refuel with a typo'd high odometer → "Unusually high … check entry" dialog → "Fix the entry" opens
      the refuel; correcting the odometer clears the flag.
- [ ] "Not now" closes the dialog and it does not reappear; tapping the chip reopens it.
- [ ] Odometer equal to the previous refuel → interval shows "Invalid entry", × on the chart, still listed.
- [ ] Chart shows every interval as a raw point (no smoothing), dashed "Your normal" line, red/amber dots.
- [ ] Lifetime average is labelled "(reference)"; it never triggers a flag.
- [ ] "Refuels every N days" and "Next refuel expected <date>" appear after the first interval.
- [ ] Delete a middle refuel in History → intervals recompute (one longer interval).

Sync / language
- [ ] Refuel lat/lng and anomaly cause appear in Supabase `refuels` after sync; second device shows the cause.
- [ ] Urdu: Fuel economy screen fully translated; chart stays left-to-right; percentages show sign.
