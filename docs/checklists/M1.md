# M1 manual test checklist (Android device, dev build)

Setup
- [ ] Supabase project created; `supabase/migrations/*.sql` applied; Phone auth enabled with an SMS
      provider (or test numbers: Auth → Providers → Phone → "Test phone numbers", e.g. 923001234567=123456).
- [ ] `.env.local` filled; dev build installed (`eas build --profile development`); `npm start`.

Auth
- [ ] Invalid number (e.g. `0423...`) shows "Enter a Pakistani mobile number".
- [ ] `0300 1234567` → code screen shows `+923001234567`; resend is disabled for 60 s.
- [ ] Wrong code shows an error; correct code lands on Home ("No vehicles yet").
- [ ] Kill app, enable airplane mode, reopen → still signed in, Home loads.

Vehicles
- [ ] Add bike: plate `lea-1234` → saved as `LEA-1234`; type required; odometer required.
- [ ] Take vehicle photo (camera) and reg-card photo (gallery); both show on the form and Home card.
- [ ] Adding a second vehicle with plate `LEA 1234` → "already have a vehicle with this plate".
- [ ] Add a car (`ICT AB-123`). Home switcher lists both; switching persists across app restart.
- [ ] Edit vehicle: change odometer start → History › Odometer shows one baseline with the new value.
- [ ] Delete vehicle (confirm) → gone from switcher; its records gone.

Entries (per selected vehicle)
- [ ] Odometer reading: lower than current shows a warning but still saves.
- [ ] Refuel: enter litres + rate → total auto-calculated on save; enter total + rate → litres calculated.
- [ ] Refuel with all three inconsistent (4 L, 250, 1100) shows mismatch warning; still saves.
- [ ] Refuel receipt photo attaches. Home "Last refuel" updates; current odometer updates.
- [ ] Service: car does not offer "Chain oil"; bike does. Cost optional.
- [ ] History tabs list refuels/services/odometer; tap → edit; delete works.

Offline + sync
- [ ] Airplane mode: add vehicle with photo, refuel, service. Settings shows "N change(s) waiting to sync".
- [ ] Reconnect → within seconds Settings shows "All changes synced"; rows visible in Supabase
      Table editor; photo in Storage › photos › `<uid>/...`.
- [ ] Edit a row in Supabase Table editor (e.g. vehicle make) → "Sync now" → app shows the change.
- [ ] Sign in on a second device with the same number → data appears (photos load via signed URL).

Language
- [ ] Settings › اردو → strings switch to Urdu; restart → layout is RTL; numbers/plates stay LTR.
- [ ] Back to English → restart → LTR.

Sign-out
- [ ] Sign out (confirm) → back to phone screen; signing in as a different number shows no old data.
