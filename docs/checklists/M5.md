# M5 manual test checklist (Android device, dev build)

Setup
- [ ] No native modules or server changes since M4: the M4 dev build and Supabase setup are fine.

Fuel price (taken from the pump display at each refuel)
- [ ] First refuel of a new vehicle with no other vehicle of its type: rate field is empty.
- [ ] Scan the pump display: rate (with litres and total) filled from the photo.
- [ ] Next refuel of the same vehicle without scanning: rate pre-filled with "Last rate you paid (<date>)".
- [ ] Enter litres only → total calculated from that rate.
- [ ] Enter litres and total (pump shows a new rate) → rate derived from them on save; no mismatch warning.
- [ ] Type a rate yourself → kept as typed (mismatch warning if it doesn't fit litres × rate).
- [ ] A second bike's first refuel suggests the rate from your other bike; a car never uses a bike's rate.
- [ ] Settings has no fuel-price section; nothing is fetched from the internet for prices.

- [ ] Settings shows the app version at the bottom.
