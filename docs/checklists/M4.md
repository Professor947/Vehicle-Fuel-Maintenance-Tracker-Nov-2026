# M4 manual test checklist (Android device, dev build)

Setup
- [ ] Rebuild the dev client (new native modules: ML Kit text recognition, expo-image).
- [ ] `supabase secrets set ANTHROPIC_API_KEY=...` and `supabase functions deploy ocr-pump`.

General (every scan)
- [ ] Scan opens the camera; the gallery icon next to it picks an existing photo instead.
- [ ] "Reading the photo…" then a dialog with the photo and editable values. Nothing changes in the form until
      "Use these values"; Cancel leaves the form untouched.
- [ ] After "Use these values" the form still needs Save — nothing is saved by scanning alone.
- [ ] A blurry/irrelevant photo → "Couldn't read this photo clearly — please type the values"; fields empty.

Add vehicle (flow 2 + 3)
- [ ] Scan number plate on a Punjab plate (e.g. LEA-1234): plate filled; plate photo becomes the vehicle photo.
- [ ] Try other formats: two-row Islamabad (ICT AB-123), Sindh (BKA-123 / KHI-2345), old-style with year (LEB-07-1234).
      Wrong reads can be fixed in the dialog or picked from "Other readings".
- [ ] Scan registration card: plate, Bike/Car and make (e.g. Honda) filled where readable; photo becomes reg-card photo.
- [ ] Scan odometer: reading filled; trip meter / speed numbers are not chosen; photo saved with the baseline
      reading (History › Odometer, synced to Storage).

Odometer reading
- [ ] Scan odometer → value proposed near the last reading; alternatives offered; saved reading has the photo.

Refuel (flow 4)
- [ ] Scan pump display in good light: litres, rate, total filled; "Read on this phone" if on-device was enough.
- [ ] Seven-segment display ML Kit can't read → "Read with Claude (online)" with the values; photo is the receipt photo.
- [ ] Airplane mode: on-device result only (or empty) — the flow never blocks; type the values.
- [ ] If the three values don't agree, the dialog warns "Litres × rate doesn't match the total".
- [ ] Scan odometer on the refuel screen fills the odometer field.

Urdu
- [ ] Scan buttons and dialog are in Urdu; numbers stay left-to-right.
